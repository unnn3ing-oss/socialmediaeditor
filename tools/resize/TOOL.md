# 尺寸（resize）

- **用途**：自訂寬高，一次把多張照片轉成同一個尺寸（裁切填滿／等比縮放），可選輸出格式。
- **來源**：舊「套版產生器」的 `resize.js`／`resize.css`，邏輯照原樣；選檔／拖曳／貼上改用 `tb.files.bind`，下載改用 `tb.download`。
- **資料存哪**：只在記憶體；改「轉換方式」「輸出格式」不會清掉照片，只有「全部清除」或重新整理會清空。
- **需要**：無（不需外掛、不需公司密碼、沒有公司素材）。
- **檔案**：`base.css`、`segmented.css`／`segmented.js`、`confirm.js` 是三個做圖工具（拼圖、尺寸、浮水印）各帶一份的共用底。
