# 拼圖（collage）

- **用途**：1080 寬的畫布，把多張照片拼成一張（等分或自由框），輸出 300 DPI 的 JPG，也能複製成圖片。
- **來源**：舊「套版產生器」的 `collage.js`／`collage.css`；選檔／拖曳／貼上改用 `tb.files.bind`，下載改用 `tb.download`。
- **資料存哪**：只在記憶體；切換等分／自由框、調整框／調整照片都不會清掉照片，只有「全部清除」或重新整理會清空。
- **需要**：無（不需外掛、不需公司密碼、沒有公司素材）。
- **檔案**：`base.css`、`segmented.css`／`segmented.js`、`confirm.js` 是三個做圖工具（拼圖、尺寸、浮水印）各帶一份的共用底。
