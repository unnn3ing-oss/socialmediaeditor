# 排程發布（fbpost，公司專屬）

- **用途**：發文到臉書粉專（可多選），立即發布或排程；看已排程（可取消）與貼文成效。後端 `/fb/*`，token 只在後端。
- **畫面**：主畫面兩個分頁「已排程／成效」＋「＋ 新增發文」彈窗（介面參照網新排程）。
- **新增發文**（照網新快速排程重做）
  - 文章網址：貼上或按 Enter 自動讀取（`/fetch/article`＋`sdk/news-*.js`）：標題自動斷行（每行 15 字）、小編文【標題】／圖說／#標籤、主圖（`/fetch/image`，失敗試下一張最多 3 張）、`/entertainment/` 自動切粉框。標題最多 4 行、每行 15（全形 1、半形 0.5）。外觀與版面照網新快速排程（網址在右欄頂端、版型只有新聞藍框／娛樂粉框、6 個粉專全列）。讀取中標題／小編文／畫布顯示骨架。小編文改過不整段覆蓋，只同步【標題】那一行。
  - 作圖框：照片（點畫布、拖曳、Ctrl+V；滾輪／雙指縮放）＋框＋標題（點兩下預覽可直接改）＋😊 T寶貼圖／馬賽克。漸層與標題位置用網新參數。**預覽就是送出的圖**（`editor.js`）。
  - 純文字：「底圖」（網新色票，底圖文字就是「標題」欄，`textcard.js`）／「臉書原生背景（實驗）」／「無底色」。
  - 留言小編文：空白＝「看更多新聞內容」＋各粉專 utm 連結，有填＝填的內容＋連結；沒有文章網址時有填才送。
  - 排入 Rundown（v8，照網新快速排程 `web/rundown.js` 搬，`rundown.js`）：開關記在瀏覽器；送出成功的粉專各寫一筆 `文章ID/圖文/SLUG` 到 FB RUNDOWN（新聞／娛樂／少康／國際＋，依 `/fb/pages` 的 `code`；擠看看、氣象略過）。純文字底圖選「無底色」或「臉書原生背景」寫 `/文字/`。排程用排程時間、立即用送出當下。SLUG 空白＝標題前 4 字。後端 `POST /rundown` 轉給 Apps Script；⚙ 可測試連線。寫入失敗不影響發文結果，訊息顯示原因。
  - 粉專晶片：點名稱勾選，「立即 ▾」選排程開時間視窗（日期、4 碼時間、↑↓、+30 分／+1 小時／明天；10 分鐘～30 天）。「全部送出（N 個粉專）」逐粉專送，晶片顯示已發布／排程時間／失敗＋重送；全部完成跳「回到列表／再發一篇」。
  - 送出進度只顯示在原送出按鈕：「正在排程到 NAME／正在發送到 NAME → 排程完成／送出完成 → 寫入 RD → 完成」。長名稱省略但可讀取完整名稱，清空與送出維持同列、送出期間皆停用；錯誤與最終摘要放按鈕列下方。數量單位一律用「個粉專」。
  - 關閉（✕、Esc）：有內容先確認，確認後清空；沒內容直接關。
- **值班粉專**（v8，`duty.js`）：第一次進來跳視窗選 1～3 個、★ 一個主要；記在瀏覽器，到下一個本機 05:00 失效（失效後全部空白重選，按「新增發文」或回到分頁時檢查）。只影響預設：晶片排序主要 → 其他值班 → 其餘、只預勾主要；已排程／已發布預設主要、值班排在下拉前面。頂列「值班 ▾」可改；「先不選」＝照原本預設。
- **本地紀錄**：預設顯示，只保存這個瀏覽器送出的內容、粉專、時間及 Facebook／RD 結果；同次重送更新同一筆。未送出草稿、token、圖片不儲存。排程時間已過標為「待確認」。預設開啟七天清除，以送出／更新／排程時間中最晚者計算，未來排程與失敗紀錄保留；可關閉自動清除或手動刪本地紀錄，皆不影響 Facebook 貼文。瀏覽器拒絕儲存時會提示僅保留本次頁面。
- **已排程／已發布**：原「成效」分頁改名「已發布」，保留看成效。列表按粉專快取在本機；重新開啟、切頁、粉專／值班變更均還原快取，不自動查 Facebook。按「刷新」成功才替換列表，失敗保留舊內容並顯示原因與上次查詢時間。載入更多合併去重並保存游標；已讀取的成效綁定列表查詢版本保存，下一次成功刷新列表才作廢。排程取消／改時間同步查詢快取及本地送出紀錄；查詢快取不受送出紀錄的七天清除影響。
- **留言通知**：工具開著每 60 秒查後端保存的失敗留言；保留分頁籤紅點＋數字、瀏覽器通知、「補留言」「知道了」，不連帶查詢 Facebook 排程／成效。
- **內容保留**：切換模式／分頁用 hidden，不清內容；彈窗只有確認關閉、清空、再發一篇會清。
- **素材**（`tool.json` 的 `assets`）：同圖片套版（`sticker.*`、`frame.*.ribbon`、`frame.logo`、`font.title`），公司素材只在後端。
- **檔案**：`tool.js`（主畫面與送出）、`records.js`（本地紀錄與清除）、`query-cache.js`（查詢快取）、`editor.js`（作圖框編輯器）、`textcard.js`（純文字底圖）、`duty.js`（值班粉專）、`rundown.js`（排入 Rundown）、`tool.css`。
- **外掛側邊欄**：外掛「發文」分頁嵌入 `panel.html?tool=fbpost`（根目錄），約 400px 寬時走既有的窄版排版（≤820px 彈窗單欄）。改這個工具的版面時，也要看側邊欄寬度。
