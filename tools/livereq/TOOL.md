# 直播需求單（livereq）

- **用途**：貼上編輯台送來的直播單（可一次多場），勾 FB 粉專、填值班小編，自動補成完整需求單並檢查缺漏；18氣象站另產生影音小幫手封面提醒。規則見 `docs/superpowers/specs/2026-11-17-livereq-design.md`。
- **資料存哪**：需求單只在記憶體（重新整理清除）。值班小編（姓名、分機或手機）存瀏覽器 `localStorage` 的 `tbx.livereq.duty`，依班別到期自動清除（使用者同意的例外）。
- **需要**：無（不需外掛、不需登入、不呼叫後端）。
- **程式**：`parse.js` 純函式（拆場、欄位、組輸出、檢查、氣象提醒、班別到期），`tool.js` 只管畫面。
