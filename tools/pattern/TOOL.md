# 圖片套版（pattern）

- **用途**：照片加標題，一鍵套框。每一組（批次）各自有照片、標題、框、貼圖／馬賽克；按「完成」存成 1080×1080 PNG（300 DPI），可逐張或「全部下載」。
- **兩種模式**
  - 沒密碼：只有「通用框（框 C）」——照片滿版、底部黑色漸層、左上角標籤（可改字，留空就不畫）、左側主色直條的標題（第一行大標、第二行副標）。主色 5 款＋自訂色。標題字型 Noto Sans TC 粗體。
  - 有密碼：另外多「新聞（藍框）」「娛樂（粉框）」（公司緞帶、白色 Logo、公司標題字型），並可切到通用框。
- **素材**（`tool.json` 的 `assets`）：`sticker.*`（貼圖）、`frame.ent.ribbon`／`frame.news.ribbon`／`frame.logo`（公司專用）、`font.title`（公司字型）。公司素材只在後端，repo 不放。
- **檔案**：`app.js`（畫面與邏輯，一般腳本）、`stickers.js`（貼圖／馬賽克／抽色）、`tool.js`（取素材、載字型、再載入前兩者）、`pattern.css`。
- **資料存哪**：只在記憶體；切換框、背景類型、收合展開各組都會保留，重新整理才清除。
- **下載檔名**：`tb.stampName`（`YYMMDDHHMM_編號.png`）。
- **注意事項**：切換一律用「隱藏」或保留狀態，不重建內容；沒密碼時介面不能出現公司字樣或選項。
- **快速填入**：卡片最上方貼文章網址（貼上或按 Enter／「帶入」）→ 後端 `/fetch/article` 取 HTML、`parseArticle` 解析；套到目前展開的那一組：公司模式依網址切娛樂粉框／新聞藍框（沒密碼維持通用框）、標題用 `autoLines` 斷行填入、主圖依序試最多 3 張（`/fetch/image`）第一張成功的走和自選檔案同一條載入路徑。已有標題或照片會先跳確認；失敗只顯示原因、不動既有內容。網址白名單由後端決定。檔案：`quickfill.js`（一般腳本，tool.js 載入）。
