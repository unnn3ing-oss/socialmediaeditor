# 數據報表（fbreports）

- **用途**：選粉專、發文類型與期間，看期間內發布貼文的發文量與累計成效（總覽、流量、粉專、類型、明細），可點原文。
- **資料存哪**：只在記憶體；重新整理、登出、權限或粉專範圍變更時清除。不寫 localStorage。
- **需要**：員工編號登入、排程發布的 `view` 權限（關閉時只有系統管理者與有 bypass 的人）；後端 `/fb/reports/posts`（`server/fb/reports.js`），權杖要有 `read_insights`。
- **注意事項**：按「查詢」才打後端；一次最多 40 批，到上限按「繼續讀取」。指標口徑在 `calc.js`（單元測試 `test/fbreports-calc.test.js`）。系統管理者有「欄位檢查」按鈕，用真實權杖實測 Graph 欄位。
