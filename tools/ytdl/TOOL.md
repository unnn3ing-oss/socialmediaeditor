# YT 批量下載（ytdl）

- **用途**：把公司 YouTube 頻道（或已取得授權）的公開影片、IG Reel 批量下載到自己的電腦，可選 720p／1080p、只下載音訊，並複製標題文字、下載封面。
- **資料存哪**：下載清單與設定由小編工具箱外掛保管（切換工具、重新整理頁面都還在）；影片存在你電腦上的資料夾（可在工具內改）。網頁只在瀏覽器記「已按過我已執行安裝檔」。
- **需要**：小編工具箱外掛，加上電腦上的「YT 下載助手」（第一次用照工具內三步驟：安裝外掛、下載並執行 YT 下載助手安裝檔、按「啟動」）。不需登入。下載走你自己電腦的網路，不經過雲端。
- **注意事項**：
  - 下載助手與下載引擎（yt-dlp）可在工具內「版本與更新」更新；外掛本身的更新由工具箱處理。
  - 連不上或下載有問題：先按「檢查環境」，再按「嘗試自動修復」；仍不行就重新執行 YT 下載助手安裝檔，或「複製診斷資訊」貼給維護的人。
  - 設定步驟區沒連好時自動展開，連好後收起，可按右上角「設定步驟」再打開（只切換顯示，不會清掉清單）。
- **與外掛的約定**：見 `tools/ytdl/PROTOCOL.md`。
