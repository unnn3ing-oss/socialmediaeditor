使用前請先確認：YouTube 條款原則上不允許用官方功能以外的方式下載；影片裡的音樂與外部素材，授權範圍可能只限 YouTube。請先取得頻道管理部門同意，轉發到其他平台前也請確認授權。如果管理部門能直接提供成品原檔，畫質會比從 YouTube 抓下來的更好。

第一次使用：三步驟設定

  1. 安裝小編工具箱外掛

    這個工具要靠外掛才能連到你電腦上的下載助手。已經裝好的話這一步會自動打勾。

    已偵測到外掛

    請到小編工具箱首頁，按頂列的「安裝外掛」。

  2. 下載並執行「YT 下載助手安裝檔」

    它會安裝下載要用的元件（Python、yt-dlp、ffmpeg 等）並測試能不能用，只要做一次。

    下載 Windows 安裝檔 Chrome 若顯示「這類檔案可能有害」，請在下載清單按「保留」，再雙擊它。

    Mac：複製下面這一行，貼到「終端機」（Cmd+空白鍵，輸入「終端機」）再按 Enter。

    改下載 Mac 安裝檔（備用）

  3. 按「啟動」連線

    連上下載助手後這一步會自動打勾，整個設定區也會收起來。

下載清單

    清單是空的。貼上網址按「增加」，影片的標題和封面會自動帶進來。
