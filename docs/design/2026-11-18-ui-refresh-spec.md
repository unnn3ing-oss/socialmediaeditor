# 小編工具箱 UI 更新設計規範（定案版）

- 日期：2026-11-18（Asia/Taipei）
- 狀態：設計方向已由使用者選定；本 PR 僅交付規範與接手計畫，尚未實作介面。
- 定案：方案 2 工具首頁＋方案 1 工作介面＋A 精簡直式下拉。
- 手機必要交付：[手機介面規範](2026-11-18-ui-refresh-mobile-spec.md)，與本規範一起實作、驗收；不是僅縮小桌面版。
- MUST＝必要；SHOULD＝建議預設，可依實測微調並記錄原因。
- 圖片示意可能有生成誤差，功能、尺寸與互動以本規範及當前程式為準。

## 1. 設計目標與範圍

維持小編熟悉的操作方式，用白底、淡灰工作區、單一藍色重點、細框線與適量留白提升效率。首頁容易找到工具，工作頁讓畫布成為主角。

### MUST
- 全站只使用一層全域頂部導覽。移除常駐第二排工具按鈕。
- 頂部順序：品牌（回首頁）、工具首頁、做圖 ▾、發文與素材 ▾；右側為現有連線／公司素材狀態及登入入口。
- 游標移到分類按鈕才展開 A 款窄版直式選單；同時支援點擊、鍵盤、觸控。
- 桌面工作頁維持左側設定、右側預覽；手機製圖頁使用局部編輯／預覽切換，其他工具採適合的單欄表單或清單，詳見手機規範。
- 保留現有工具能力、資料生命週期、登入權限、公司素材解鎖與既有 SDK 合約。
- UI 字型與配色只影響操作介面，不改 canvas 成品的框、字型、尺寸、色彩、DPI 或檔案命名。

### 本次不包含
- 深色主題、米白墨綠主題（B 為備選，不是目前實作目標）。
- 新增雲端專案、自動儲存、草稿永久保存、使用統計、LINE 直接發送。
- 恢復並排工具、重寫框架、改後端／下載助手或更換登入機制。
- 管理後台全面重排。共用 tokens 若影響後台，需驗證既有頁面。

## 5. 全域頂部導覽：A 精簡直式下拉（必要）

桌面高度 64px；左右內距 24px；品牌與導覽間距 24px。背景白、底部 1px 分隔線、無厚陰影。可以 sticky，但不能遮擋焦點與內容。只有此列為全域導覽。

```text
[編 小編工具箱]  工具首頁  做圖 ▾  發文與素材 ▾       [連線狀態] [登入／公司狀態]
                           ┌───────────────┐
                           │ ▧ 圖片套版  ✓ │
                           │ ◯ LINE 推播   │
                           │ ▦ 拼圖        │
                           │ ◇ 浮水印      │
                           │ ⌗ 尺寸        │
                           │ ✎ 設計        │
                           └───────────────┘
```

上面圖示僅為位置示意，正式使用既有圖示；做圖選單順序與現有 catalog 相同。發文與素材選單依序為排程發布、直播需求單、YT 批量下載。

### 外觀
- 寬度 240px，最小 220px；左右內距 8px，上下 8px；每列 padding 10px 12px。
- 圖示＋名稱，名稱不得截斷；右側顯示目前工具勾選。不放用途說明、縮圖或雙欄。
- 已選列：accent-soft 底、accent 字、勾選；hover 列：fill 底；focus-visible 有明確外框。
- 錨定分類鈕下方，視覺距離 8px，距視窗邊界至少 12px。用透明橋接區跨越間隙，游標往下移時不關閉。
- overlay 不占文件流，不推開設定區、不產生第二排工具列；避免被父層 overflow 裁切。
- 最大高度 min(420px, 可用視窗高度)，必要時選單內可捲，不能跑出視窗。
- 圖層：header 100、dropdown 110、modal 1000；確認現有 dialog 與 iframe 的堆疊順序。

### 狀態與輸入行為
- 初始關閉。精準游標且支援 hover 時，pointerenter 150ms 後開啟；快速路過不開。
- 同時最多一個分類展開；移到另一分類 150ms 後切換。按鈕與其選單為同一互動區。
- pointerleave 200ms 後關閉；回到按鈕或選單立即取消關閉計時器。
- 分類鈕 click 可開關，觸控不依賴 hover；不要同時觸發開啟與切換工具。
- 點選工具：走既有 onOpen(id)，收起選單，更新目前工具。回首頁也收起。
- 點外部、Escape 關閉；Escape 將焦點還給觸發鈕。焦點移到整組外也收起，不擅自搶回焦點。
- 進入 iframe 的點擊也算外部；父頁不能只依賴會在 document 冒泡的 click，需測試 focus／window blur 或既有 SDK 能力，不新增跨來源敏感存取。
- hover 開啟不搶鍵盤焦點；鍵盤焦點仍在選單內時，不因滑鼠離開就關閉。
- 建議採 disclosure navigation：原生 button＋aria-expanded＋aria-controls，面板內原生可操作元素；不加 role=menu，除非完整實作 menu 鍵盤模式。
- Enter／Space 開關分類；Tab／Shift+Tab 正常走訪；ArrowDown 從分類開啟並聚焦第一項；Escape 行為如上。選中工具名稱與勾選可由輔助技術辨識。
- 選取後把焦點移至可見工具內容的既有焦點入口／標題；不可留下焦點在 hidden 選單或 hidden iframe。
- 被權限限制的工具仍保留現有說明流程，不因新選單而繞過驗證或讀取受限資料。

## 6. 首頁：方案 2 完整工具入口

- 內容最大寬 1280px，置中，桌面左右 32px／上下 32px，手機 16px。
- 標題「今天要完成什麼？」；說明「製圖、整理需求、下載素材，從這裡開始。」
- 做圖 6 項與發文與素材 3 項分組；順序、名稱、入口來自 registry／catalog 的既有資料，不手寫第二份工具清單。
- 桌面 3 欄、gap 16px；每卡約 144–160px 高。左側圖示／名稱／一句用途，右側約 104×80 的公開縮圖（若空間不足可隱藏縮圖）。
- 卡片有單一清楚可點目標，整張可按，不能卡片 button 內再巢狀互動按鈕。
- hover 只改細線／淡底，不上浮；focus-visible 清楚；小字最多 2 行並可取得完整說明。
- 狀態標示：排程發布「管理員測試」；YT「需要外掛」「需要下載助手」。依真實狀態提供手動安裝入口。
- 未登入不能預載公司素材、公司縮圖或在公開 repo 放公司資產。
- 搜尋工具屬 SHOULD 的小型增強；如實作，只過濾現有工具，不呼叫新服務；需有 label、清除、無結果與空搜尋還原。
- 首頁可顯示一次非阻斷提示：製圖內容多暫存本頁，重新整理前先下載；設計可存專案。不要彈出強制安裝外掛。

## 7. 工作介面：方案 1

- header 下直接進工作區；一般桌面 16px 外距、16px 欄距；不加常駐全域次導覽。
- 左側設定欄 340px（允許 320–360px），右側 minmax(0, 1fr)。優先讓設定與預覽共用清楚捲動規則，避免三層巢狀捲軸。
- 標題、用途、網址帶入放設定區；設定用標籤、留白與細分隔線分組，避免卡片內再包卡片。
- 內容／貼圖／輸出等局部 tabs 只在確實需要時出現在工具面板內，不得形成第二層全域工作列；保留目前每工具所有設定。
- 畫布所在 stage 使用中性淺灰；預覽維持真實輸出比例、可 contain 縮放，不可裁切成品來填滿容器。
- 桌面常用 1280×800 視窗目標：方形預覽約 460–560px；依實際可用高度縮放，不硬塞固定 600px。
- 預覽上方僅有局部「預覽」與真實尺寸／格式，不能新增假縮放功能。
- 貼圖／馬賽克／抽色等局部操作放畫布附近，逐步減少圖示旁多餘外框。
- 本次圖片列使用 72–96px 縮圖，橫向捲動限定此列，不推寬全頁；選中以藍框＋文字標示。
- 保留目前「產生此張」「下載這張」「全部下載」功能差異。未產生／錯誤／下載中的狀態要真實，不能假顯示成功。
- 產生與單張下載放左設定區尾端；全部下載放縮圖列右側。窄螢幕改可換行的底部操作群組，不遮住欄位。
- 當前工具資料在切換、回首頁再返回時保留：沿用 createPanes.ensure／sync 的 lazy iframe＋hidden，不能重設 src、remove 或重新建立 iframe。

## 8. 非製圖工具布局

- 直播需求單：輸入區、逐場欄位補齊、缺漏提示、完成輸出；桌面可左右，手機上下。保持多場解析與班別到期規則。
- 排程發布：維持管理員驗證、手動查詢、時間檢查、既有操作確認；清單依寬度重排，不改 API 及權限。
- YT：連線狀態／設定步驟／下載佇列；已連好收起設定，失敗顯示診斷入口；不因新版首頁改掉外掛保管清單。
- 局部清單、表單、表格使用同一字級、按鈕與狀態 tokens，但不刪除資訊或硬改為大卡片。

## 9. RWD 與可及性

| 視窗寬度 | 導覽／首頁／工作區 |
|---|---|
| ≥1200px | 單列完整導覽；首頁 3 欄；設定 340px＋預覽 |
| 821–1199px | 單列導覽、縮減非必要文字；首頁 2 欄；設定 320px＋彈性預覽 |
| ≤820px | 單列 56px header：品牌＋工具按鈕＋登入；點工具開浮層，內以做圖／發文與素材分組；首頁 1 欄；製圖局部編輯／預覽切換，其他工具單欄 |

- 820px breakpoint 對齊現有 shell；821px 仍須測試放得下，必要時提早收斂右側狀態至可開啟詳情的入口。
- 手機不新增常駐第二列導覽，完整公司／連線狀態放在可點開面板；不得截斷關鍵到期或錯誤資訊。
- 320／375／390／768／820／821／1024／1280／1440px 無整頁水平捲動；只有合理的縮圖列／資料表內可橫捲。
- min-width:0、grid minmax(0,1fr)；保留先前 iPhone iframe 防撐寬處理，不以 body overflow-x:hidden 掩蓋問題。
- 所有可操作區域目標至少 44×44px；必要 label、替代文字、錯誤關聯、skip link、焦點可見與合理順序。
- 文字放大 200%、320 CSS px reflow、橫向手機與螢幕鍵盤開啟可完成主要任務；sticky 區不能遮蔽焦點。
- prefers-reduced-motion 停用非必要轉場；hover/focus 選單可停留、可關閉，不僅滑鼠可操作。

手機詳細配置、鍵盤／安全區、iframe 捲動、各工具觸控行為與 M-01～M-12 驗收，見 [手機介面規範](2026-11-18-ui-refresh-mobile-spec.md)。這些是同批必要交付，不是後續可選優化。

## 10. 動效與狀態

- 預設轉場 120ms ease-out，僅 background／border／opacity；選單可 4px 淡入，不做彈跳或大位移。
- 載入、空清單、未連線、失敗、停用、成功明確區分，沿用既有錯誤原因與重試方式。
- 不憑登入按鈕推論已登入，不憑點下載推論成功，不新增「已儲存」假狀態。
- 計時器在重繪／清理時移除，避免重複事件監聽與快速移動造成多選單並存。

7. 更新同一份 handoff，記錄完成範圍、測試、截圖位置與未處理項。
