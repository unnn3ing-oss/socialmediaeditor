# 小編工具箱（socialmediaeditor）— 設計規格

- 日期：2026-11-05（第 2 版：改為積木架構）
- 狀態：**草稿，待使用者審閱**
- 設計稿（Claude Design 畫布）：https://claude.ai/artifact/EM2eVNTjYAV91awcKRAcJ1　定案稿為 S5、S6 兩排

## 0. 一句話

**一個網站＋一個外掛＋一個後端**，最終成為唯一的小編工具。工具是一塊一塊的「積木」：新增或移除工具只要動那個工具的資料夾和一行清單，**核心不用改，也不用重讀整個專案**。

## 1. 目標與範圍

| 痛點 | 對應做法 |
|---|---|
| 切換網站太麻煩 | 一個網址，上方工具列切換，可左右並排兩個工具 |
| 外掛太多太亂 | 合成一個外掛「小編工具箱」 |
| 要給同事用 | 開站先看到櫥窗；狀態列直接告訴你缺什麼 |
| 未來會增減工具 | 積木架構（第 4 節） |
| 公司素材不外流 | 輸入公司密碼才出現公司素材，沒輸入一律通用版（第 5 節） |

### 不做
深色模式、「最近的作品」、剪輯（已搬到 QuickCut）、常用小編文範本、熱門新聞庫相關功能（自用，不納入）。草稿雲端同步先不做，但保留做法（第 7.3 節）。

### 舊工具不退場
QuickPatterntool、LinePushPatternTool、-schedulenewnet、videodownload 的網站、外掛、`snn-images` 後端**照常運作**。程式**複製**進本 repo，新站是主力。

> 已知事實：公司素材目前已在舊網站公開。新站的密碼只保證「新站」不露出，不改變舊站。

### 收錄的工具

| 群組 | 工具 | 來源 | 等級 | 需要 |
|---|---|---|---|---|
| 做圖 | 圖片套版 | QuickPatterntool `app.js` 等 | 通用（公司素材另外解鎖） | — |
| 做圖 | LINE 推播 | LinePushPatternTool `index.html` | 通用（公司素材另外解鎖） | — |
| 做圖 | 拼圖 | QuickPatterntool `collage.*` | 通用 | — |
| 做圖 | 浮水印 | QuickPatterntool `watermark.*` | 通用（公司 Logo 另外解鎖） | — |
| 做圖 | 尺寸 | QuickPatterntool `resize.*` | 通用 | — |
| 做圖 | 設計 | QuickPatterntool `design-*` | 通用 | — |
| 發文與素材 | 網新排程 | -schedulenewnet `web/` | **公司專屬** | 外掛、網新登入 |
| 發文與素材 | YT 批量下載 | videodownload `web/` | 通用 | 外掛、本機下載助手 |

## 2. 資訊架構與互動（已定案）

| 規則 | 內容 |
|---|---|
| 開站 | **每次**開站先顯示櫥窗，點卡片進入；左上角 Logo＋「小編工具箱」回櫥窗 |
| 工具列 | 在上方，圖示＋文字 |
| 單點 | 點上方工具 → 該工具**全頁** |
| 並排 | 把上方工具**拖進工作區左半或右半** → 左右並排，**最多 2 格** |
| 第三個工具 | 並排中單點第三個 → **取代最後操作的那一邊** |
| 最後操作 | 藍框標示 |
| 同一工具 | 同時只開一格；拖到另一側＝換邊 |
| **內容保留** | 在網站裡切換工具、取代、關閉窗格，以及**工具內部切換功能**（分頁、模式），填入的內容一律保留；只有工具內「清空」才刪除。**重新整理或關閉分頁可以清除內容** |
| 公司模式 | 頂列有「公司素材」入口：輸入密碼後解鎖；未解鎖時公司專屬工具不出現在櫥窗和工具列 |

## 3. 視覺設計（已定案）

### 3.1 基調
S3「安靜中性」，**所有按鈕都有框**，無深色模式。字型 Noto Sans TC。

### 3.2 色彩 token

| token | 值 | 用途 |
|---|---|---|
| `--surface` | `#ffffff` | 頂列、卡片、輸入框 |
| `--stage` | `#f6f7f8` | 工作區底 |
| `--line` | `#e3e4e6` | 分隔線 |
| `--line-strong` | `#c4c7cc` | 控制項框線 |
| `--text` | `#202124` | 主要文字 |
| `--muted` | `#55595f` | 說明文字 |
| `--btn-text` | `#3c4046` | 次要按鈕文字 |
| `--accent` | `#1d4fb8` | 主色、選取、焦點 |
| `--accent-strong` | `#163d8f` | 主按鈕框線 |
| `--accent-soft` | `#eef3fc` | 選取底 |
| `--placeholder` | `#d5d8dc` | 縮圖佔位 |
| `--fill` | `#f1f2f4` | 開關底 |
| 狀態綠 | 底 `#e8f5ec`／框 `#a8d5b5`／字 `#17682e` | 正常 |
| 狀態橘 | 底 `#fff4e0`／框 `#e8c48a`／字 `#8a4b00` | 需要處理 |

文字對比 ≥ 4.5:1。

### 3.3 元素

| 元素 | 選擇 | 規格 |
|---|---|---|
| Logo | **A 套版框** | 圓角外框＋照片＋兩行標題，24 viewBox |
| 主按鈕 | **C 膠囊** | 高 44、`border-radius: 999px`、實心 `--accent`＋`--accent-strong` 框 |
| 次要按鈕 | **A 白底** | 白底、`--line-strong` 框、`--btn-text` 字 |
| 按鈕效果 | **C 內壓** | 滑過：主按鈕底 `#1a47a6`，次要框與字變 `--accent`；按下：`scale(.97)`，主按鈕 `inset 0 2px 4px rgba(0,0,0,.3)`，次要底 `--accent-soft`；鍵盤焦點：2px `--accent` 外框、偏移 2px；停用：底 `#eceef0`、字 `#6b7077` |
| 上方工具 | **C 圖示＋文字** | 16px 線條圖示 |
| 二選一 | **乙 開關＋兩側文字** | 開關 48×28；選中那側文字 `--accent` 粗體；`role="switch"` |
| 櫥窗卡片 | **A 圖在上** | 112px 成品示意＋名稱＋一句說明 |
| 輸入框 | **A 標籤在上** | |
| 狀態 | **B 框線＋圓點** | |
| 最後操作 | **A 藍框** | |

### 3.4 前端規範
- 櫥窗網格 `repeat(auto-fit, minmax(240px, 1fr))`、間距 24px。
- **骨架屏取代轉圈**：與完成後同尺寸，`aria-busy`；`prefers-reduced-motion` 時停止微光。
- 動態數字一律 `font-variant-numeric: tabular-nums`。
- 動畫只用 `transform`／`opacity`。

## 4. 積木架構

### 4.1 四層

```
┌──────────────────────────────────────────────────────────┐
│ 外殼（共用平台介面）                                       │
│ 櫥窗、工具列、並排、狀態列、公司素材入口 ← 由工具清單自動產生 │
├──────────────────────────────────────────────────────────┤
│ 工具模組（積木）  tools/<id>/                              │
│        │ 只透過 ↓ 溝通，不直接碰外掛、後端、其他工具           │
├──────────────────────────────────────────────────────────┤
│ SDK（共用服務層）  tb.*                                    │
│ 檔案、下載、狀態、日誌、素材、外掛呼叫、後端呼叫                 │
├───────────────────────┬──────────────────────────────────┤
│ 統一外掛（核心＋模組）   │ 後端 toolbox-api（核心＋模組）     │
│ cookie、下載、本機助手   │ 公司密碼、素材、日誌、抓網頁、        │
│                       │ 圖床、定時任務、工具專屬路由          │
└───────────────────────┴──────────────────────────────────┘
          後端資料：D1（資料表）、R2（檔案）、KV（快取）
```

### 4.2 工具放進同一頁的方式：同網域 iframe
外殼負責櫥窗、工具列、並排；每個工具是獨立頁面 `tools/<id>/index.html`，用同網域 iframe 載入。

| 理由 | 說明 |
|---|---|
| 積木彼此隔離 | 各工具的全域變數、CSS 互不干擾，搬舊程式改動最少 |
| 內容自然保留 | 切走時 iframe 只隱藏不銷毀 |
| 新增／移除乾淨 | 一個資料夾就是一個工具 |

拖曳並排時，外殼在 iframe 上蓋一層透明放置區（iframe 會吃掉滑鼠事件）。

### 4.3 工具規格卡 `tools/<id>/tool.json`

```json
{
  "id": "watermark",
  "name": "浮水印",
  "group": "做圖",
  "desc": "Logo 自動放在照片最暗的角落",
  "icon": "icon.svg",
  "thumb": "thumb.svg",
  "entry": "index.html",
  "tier": "public",
  "requires": [],
  "assets": {
    "logo.default": { "company": "tvbs-news-logo.svg", "public": "upload" }
  },
  "ext": null,
  "api": null,
  "sdk": 1
}
```

| 欄位 | 意思 |
|---|---|
| `tier` | `public` 所有人可用；`company` 有公司密碼才出現 |
| `requires` | `extension`、`login:tvbs`、`helper`。狀態列與卡片提示依此自動顯示 |
| `assets` | 這個工具用到的素材，各自寫公司版與通用版，SDK 自動挑 |
| `ext` | 需要的外掛權限、背景處理程式 `ext.js` |
| `api` | 後端路由模組 `api.js`，掛在 `/t/<id>/…` |
| `sdk` | 使用的 SDK 主版號；SDK 升級時可以檢查相容性 |

### 4.4 工具清單 `tools/registry.json`
列出**啟用中**的工具 id，順序就是櫥窗順序。新增工具＝加一行；停用工具＝刪一行，資料夾可以留著。

### 4.5 SDK `sdk/toolbox.js`（工具唯一能用的介面）

| 功能 | 介面（示意） | 說明 |
|---|---|---|
| 檔案 | `tb.files.pick()`／`onDrop()`／`onPaste()` | 點選、拖曳、Ctrl+V 統一處理 |
| 下載 | `tb.download(blob, name)`／`tb.download.batch(list)` | 統一檔名規則（`YYMMDDHHMM_第幾張`）與批次間隔 |
| 狀態 | `tb.status.get('extension')`、`tb.status.on(...)` | 外掛、網新登入、下載助手、公司模式 |
| 素材 | `tb.assets.get('logo.default')` | 依公司模式回傳公司版或通用版 |
| 外掛 | `tb.ext.call(op, payload)` | 統一的外掛協定 |
| 後端 | `tb.api.call(path, body)` | 自動帶公司憑證 |
| 日誌 | `tb.log.error(code, info)` | 只記工具、錯誤代碼、瀏覽器版本，**不記標題、小編文、網址** |
| 樣式 | `ui/tokens.css` | 第 3 節的 token、按鈕、開關、骨架 |

**規則**：SDK 只能「加」功能，不改既有介面的意思；需要破壞性修改時升 `sdk` 主版號，並保留舊版轉接。

### 4.6 組裝腳本 `node build.js`
- Chrome 規定外掛權限要事先寫在 `manifest.json`，所以需要這一步。
- 讀 `registry.json` 和各工具的 `tool.json`，自動產出：
  - 外掛的 `manifest.json`：權限取聯集；
  - 外掛的背景路由表；
  - 後端的路由表；
  - 櫥窗資料。
- 純 Node 腳本，不用框架、不用安裝套件。
- 同時檢查每張規格卡是否填寫正確，有錯就停下並說明。

### 4.7 給未來維護者（含 AI）的說明
| 檔案 | 用途 |
|---|---|
| `tools/_template/` | 新工具範本，複製改名即可 |
| `sdk/README.md` | SDK 每個功能一行說明，開發工具時只讀這份 |
| `tools/<id>/TOOL.md` | 這個工具的用途、資料存哪、注意事項 |
| `CLAUDE.md` | 規則：**改工具只讀該工具資料夾＋`sdk/README.md`**；改核心才讀 `shell/`、`sdk/`、`server/` |

## 5. 公司模式

### 5.1 運作方式
1. 頂列「公司素材」→ 輸入**一組公司密碼**。
2. 後端驗證後發憑證，**30 天有效**；常用的話自動續期，作法比照 `snn-images`。
3. 有憑證時：
   - 公司專屬工具出現在櫥窗和工具列；
   - `tb.assets` 改回傳公司版素材；
   - 公司設定（粉專、UTM、hashtag）從後端載入。
4. 沒有憑證時：一律通用版，公司專屬工具隱藏。
   使用中過期時：**自動跳出登入彈窗**；已開著的公司工具窗格與內容保留（蓋一層鎖定提示），重新輸入密碼後解除；按「取消」則保持鎖定，提示上有「重新輸入」可再叫出彈窗。
5. 要讓所有人立刻失效：在後端更換密碼或簽章金鑰。
6. 公司素材只在憑證有效時快取在瀏覽器；登出或過期就清掉。

### 5.2 公司專屬清單（沒密碼一律改用通用版）

| # | 項目 | 沒密碼時的通用版 |
|---|---|---|
| 1 | TVBS NEWS 向量 Logo（浮水印） | 上傳自己的 Logo |
| 2 | 舊版「新聞網」Logo | 同上 |
| 3 | 套版：娛樂粉框、新聞藍框、角落緞帶、白色 Logo | **通用套版框**（無 Logo，顏色自選）※需新設計 |
| 4 | LINE 推播黃色標題條 | 無標題條底圖（`template-plain.png` 本身就是通用版） |
| 5 | LINE 推播娛樂四格拍立得版型 | **通用四格**※需新設計 |
| 6 | T 寶貼圖 7 張 | **通用表情貼圖**（開放授權，例如 Noto Emoji，Apache 2.0）※需挑選 |
| 7 | LINE 帳號名稱「TVBS新聞」「TVBS娛樂頭條」 | 空白或自填 |
| 8 | 粉專清單與 UTM 參數 | 只在網新排程使用，跟工具一起隱藏 |
| 9 | 固定 hashtag | 同上 |
| 10 | tvbs.com.tw 網址規則與範例 | 改成通用說明「貼上文章網址」 |
| 11 | Rundown 粉專區段與試算表 | 跟網新排程一起隱藏 |
| 12 | **網新排程**整個工具 | 不顯示 |
| 13 | 頂列「網新已登入」狀態 | 不顯示 |

> 已知事實：網新排程的**程式碼**本來就公開在 -schedulenewnet；藏的是工具入口和公司設定（#8～#11 改由後端提供），程式碼本身不含密碼。

### 5.3 公司素材怎麼上傳
後端提供一個**管理頁**，用另一組管理密碼登入，可以上傳、替換、刪除公司素材。以後換 Logo 或版型只要在這裡換，**不用改程式、不用重新部署**。

## 6. 後端 toolbox-api（新建）

- 平台：Cloudflare Worker（你現有帳號），資料用 D1、R2、KV。
- 舊的 `snn-images` 繼續服務舊網站，不動它。

| 模組 | 路由 | 功能 | 資料 |
|---|---|---|---|
| auth | `POST /auth`、`GET /auth/status` | 公司密碼換憑證、狀態查詢 | 簽章金鑰放 Secrets |
| assets | `GET /assets/manifest`、`GET /assets/<key>` | 依憑證回傳公司版或通用版清單與檔案 | R2＋D1 |
| admin | `/admin/*` | 管理頁：上傳、替換公司素材 | 另一組管理密碼 |
| logs | `POST /logs` | 收集錯誤（不含內容），保留 30 天 | D1 |
| fetch | `GET /fetch?url=` | 代抓公開網頁的標題與 OG 圖；只允許白名單網域 | KV 快取 |
| fb | `GET /fb/pages`、`/fb/posts`、`/fb/scheduled`、`/fb/insights`、`POST /fb/post`、`GET /admin/fb` | 臉書粉專：清單、貼文成效、發文／排程（需公司憑證）；管理頁檢查 token 狀態。只放行這些動作，不做萬用代理 | 粉專 token 放 Secrets（`FB_TOKEN`），KV 快取 |
| imghost | `/t/sched/upload`、`/i/<key>` | 圖床（從 `snn-images` 複製），3 天自動刪除 | R2 |
| rundown | `/t/sched/rundown` | 轉送 Rundown 到 Apps Script（從 `snn-images` 複製） | Secrets |
| cron | 每日 | 清理過期圖床檔案、日誌 | — |

- 工具專屬路由放在 `tools/<id>/api.js`，`build.js` 自動掛到 `/t/<id>/`。
- 必要 Secrets：`COMPANY_PASSWORD`、`ADMIN_PASSWORD`、`SESSION_SECRET`；Rundown 另需 `RUNDOWN_URL`、`RUNDOWN_TOKEN`；臉書另需 `FB_TOKEN`（選填 `FB_APP_ID`、`FB_APP_SECRET`）。
- CORS 只允許工具箱網址。
- **部署要你在 Cloudflare 操作**（建立 D1、R2、KV、設定 Secrets）。我會寫好逐步說明和 `wrangler.toml`。

### 仍然不放後端
| 功能 | 原因 |
|---|---|
| 網新排程「送出」 | 要用瀏覽器裡的網新登入 cookie，留在外掛 |
| YT 下載 | 推論：雲端機房 IP 常被擋、流量大、有條款風險，留在本機下載助手 |
| 做圖的編輯與輸出 | 瀏覽器處理較快，不必上傳大照片 |

## 7. 資料保存

### 7.1 網站使用期間（記憶體，不寫硬碟）
1. 切換工具、取代、關閉窗格：iframe 只隱藏不銷毀，工具的狀態自然留在記憶體。
2. **工具內部切換功能**（例如新聞／娛樂、圖片背景／純色背景、工具內分頁）：用「隱藏」切換，不要重建畫面；各模式的內容各自保留。這條寫進 `sdk/README.md` 與工具範本，P1 搬每個工具時都要測。
3. 只有工具內「清空」會清掉內容。
4. **重新整理、關閉分頁會清除內容**（使用者決定），所以不需要 IndexedDB 保存。

### 7.2 公司模式快取
公司素材只在憑證有效時快取，失效就清除。

### 7.3 草稿雲端同步（先不做，保留做法）
若未來要做，需先在 SDK 加一個保存介面（工具改成透過它存取狀態）。採最省容量的方式：
- 只同步文字和設定（JSON，每份約 2～10 KB）。
- 照片不上傳，只記 SHA-256 指紋、檔名、尺寸；換電腦後重新放入同一張照片，就會自動套回裁切位置。
- 網址來源的圖只記網址。
- 每人每工具只留最新一份；14 天未開自動刪除。

## 8. 統一外掛「小編工具箱」

- **核心**：網站橋接（`postMessage`，`source`＋`nonce`＋`op`，使用新前綴）、背景路由、版本更新，沿用 QuickPatterntool 的檢查更新流程。
- **模組**：各工具的 `ext.js` 註冊自己的 `op`；權限由 `build.js` 從規格卡匯總。
- **注入範圍**：只注入 `https://unnn3ing-oss.github.io/socialmediaeditor/*`，`all_frames: true`。
- **與舊外掛並存**（已知事實）：
  - 舊外掛只注入自己的網址，在新站不會重複回應。
  - 新外掛**不注入**熱門新聞庫。
  - facebook.com 相關功能留到 P3，到時再設計「偵測到舊外掛就讓給舊外掛」的機制。
- **YT 下載助手**（已知事實）：`videodownload/host/installer.py` 的 `allowed_origins` 只寫一個外掛 ID。要改成同時允許新舊兩個外掛，已裝的人重跑一次安裝程式。**這會改到 videodownload repo，P2 時另外請你確認。**
- **固定外掛 ID**：`manifest.json` 加 `key`（比照 videodownload），每台電腦的外掛 ID 都相同，下載助手的 `allowed_origins` 才能寫死。
- **側邊欄**：第一版只放「開啟小編工具箱」與狀態。
- **版本**：從 `1.00` 開始，規則比照 QuickPatterntool（`manifest.json`、`changelog.json`）。

### 8.1 安裝與更新（比照「網新快速排程」）
程式從 -schedulenewnet 的 `web/installer.js` 複製改名。

| 步驟 | 做法 |
|---|---|
| 入口 | 頂列「安裝外掛」開 5 步驟全螢幕教學；電腦版開站偵測不到外掛時自動跳出（手機不跳） |
| 一鍵安裝檔 | 網頁從 GitHub 抓最新的 `extension/`（每個檔案以 git blob SHA 驗證），打包嵌進 Windows `toolbox-install.cmd`／Mac `toolbox-install-mac.sh`，安裝檔執行時不用再連網 |
| 安裝檔做的事 | 放到「文件」裡的 `toolbox-ext`（同名資料夾不是這個外掛就停下、不覆蓋）→ 路徑複製到剪貼簿 → 打開 `chrome://extensions` |
| 使用者要自己點 | 「開發人員模式」→「載入未封裝項目」→ 貼上路徑（Chrome 不允許程式代按） |
| 安裝畫面 | Windows：一般安裝視窗（開始 → 進度 → 兩步圖解；失敗可重試、複製錯誤訊息），開不起來時退回文字模式。Mac：終端機執行 `bash ~/Downloads/toolbox-install-mac.sh`，過程用系統對話框 |
| 公司電腦擋安裝檔 | 教學裡可改用「選擇資料夾並寫入」或下載 ZIP |
| 自動更新 | 每小時、Chrome 啟動、打開側邊欄時檢查 GitHub；有新版時圖示顯示紅色「新」，側邊欄跳出彈窗。按「立即更新」第一次選外掛資料夾（之後記住），只寫入有變動的檔案，完成後重新載入外掛 |

- `build.js` 產生的 `extension/manifest.json` 要一起提交，安裝檔和自動更新才抓得到。
- YT 下載的**本機下載助手**仍用 videodownload 自己的安裝程式；P2 再評估是否併進同一個安裝檔。

## 9. 分階段

| 階段 | 內容 | 完成時給你看 |
|---|---|---|
| **P0 地基** | 外殼（櫥窗、工具列、並排、取代、狀態列）、`tokens.css`、SDK 第 1 版、`registry.json`＋`tool.json`＋`build.js`、`_template`、外掛核心、後端核心（auth、assets、admin、logs、fetch、cron）與部署說明、規格卡檢查、e2e | 可操作的外殼＋一個示範工具；後端在你帳號部署成功 |
| **P1 通用做圖工具** | 先出通用版素材設計稿（套版框、四格、表情貼圖）給你選；再搬入拼圖、尺寸、設計、浮水印、圖片套版、LINE 推播，接上公司素材，並逐一測試工具內切換功能不會清掉內容 | 六個工具可用；有密碼／沒密碼兩種畫面 |
| **P2 外掛＋發文工具** | 網新排程（含圖床、Rundown 模組）、YT 下載、外掛模組、videodownload 安裝程式 ID 調整（另一個 repo） | 同事只要裝一個外掛 |
| **P3 補齊** | 側邊欄功能、facebook 相關功能（與舊外掛的重複回應處理） | 舊外掛功能都有對應 |

- 舊工具分兩步接上：先「包」進來，只換外掛呼叫和素材，並確認工具內切換功能不會清掉內容；工具內部完全改用 SDK，等之後修改那個工具時再做。
- **開發方式**：主對話分派，依工作性質派子代理；每階段結束彙整「改了什麼」。
- **合併規則**：只推開發分支（以對話指定的為準），**你確認後才併入 main**。

## 10. 測試
- **單元測試**：`node --test test/*.test.js`，搬入工具時帶入原 repo 的測試。
- **規格卡檢查**：每個 `tool.json` 欄位正確、`registry.json` 裡的 id 都存在、公司素材沒有混進 repo。
- **後端**：各路由的單元測試，含憑證過期、密碼錯誤、未授權取公司素材。
- **外殼 e2e**（Playwright，`/opt/pw-browsers/chromium`）：
  - 開站顯示櫥窗；
  - 單點全頁；
  - 拖曳並排；
  - 第三個工具取代最後操作的那一邊；
  - 切換工具、取代、關閉窗格後內容仍在；工具內部切換功能後內容仍在；
  - 清空後內容消失；
  - 有公司憑證／沒有公司憑證時，櫥窗與素材正確；
  - 鍵盤可操作。
- **積木測試**：用 `_template` 新增一個假工具、再移除，確認核心檔案零修改。
- **外掛**：沙盒沒網路，`chrome.*` 以 stub 驗證參數。
- **視覺**：每階段截圖，和設計稿 S5／S6 對照。

## 11. 決策紀錄

| 決策 | 結果 |
|---|---|
| 整合方式 | 1 個網站＋1 個外掛＋1 個後端；舊工具並存 |
