# 直播需求單工具（livereq）設計

- 日期：2026-11-17　- 狀態：使用者已確認（「開始」）
- 目的：編輯台送來的直播單，讓小編快速知道要加上哪些 FB 粉專、值班小編、內文，並補成可直接回傳的完整需求單。

## 目標／非目標
- 目標：貼上（可多場）→ 自動拆場 → 勾 FB 粉專 → 自動補粉專、值班小編、內文 → 檢查缺漏 → 複製。
- 目標：18氣象站另外產生「影音小幫手封面提醒」。
- 非目標：不發文、不呼叫後端、不保存需求單內容、不做計時通知（1530 沒收到氣象單只寫在說明）。
- 反目標：改動原需求單既有文字（導播好～、重N、直播不刪、hashtag 都要原樣保留）。

## 做法（方案）
| 方案 | 取捨 | 結論 |
|---|---|---|
| 新獨立工具 `tools/livereq/`（純前端） | 不碰後端、外掛不升版；人人可用 | **採用** |
| 放進排程發布 fbpost | fbpost 目前只開放管理員，流程也無關 | 不採用 |

## 解析規則
- 欄位行：以 `●` 或 `◎` 開頭（前面可有空白），欄位名稱＝冒號（`：`／`:`）前的字，值＝冒號後同一行＋之後到下一個欄位行前的所有行。
- 欄位分類（只看欄位名稱）：含「事件」→ 新聞事件；含「平台」→ 直播平台；含「畫面來源」或「直播形式」→ 畫面來源；含「時間」→ 直播時間；含「標」→ 標題；含「文」→ 內文（同時含「標」與「文」算標題）。
- 拆場：出現第二個「新聞事件」欄位、或出現開場行（非欄位行且含 `導播好`、`直播需求`、`===` 的前一段標題）時開新的一場；說明行（例如「2100看世界粉專直播請確認」）跟著下一場。
- 新聞事件：`新聞事件` 欄位值 → 開頭 `【】`／`《》` 內的字（去 `#`、`TVBS`、時間 `21:00`/`2100`）→ 空白則要手動補。後面接上整張單出現的「重N」。
- 平台：值裡含 `FB`／`臉書` 的行算 FB；其餘非空行算 YT。

## 輸出規則（原文保留，只插入）
- 直播平台：
  - 原本沒有 FB 行 → 原 YT 行前插 `YT:`，最後接 `FB:` 段落（勾選粉專一行一個）。
  - 原本有 FB／臉書行 → 不動，勾選粉專接在後面（同一行用 `、` 接；`FB：` 換行式就一行一個）；「新聞」與「新聞粉」視為同一個不重複。
  - 平台欄位不存在 → 新增 `●直播平台：` 段。
- 畫面來源：值空白或「待補」→ 值寫「待補」；欄位不存在 → 補 `●畫面來源：待補`（放在平台段之後）。
- 值班小編：插在畫面來源值的下一行：`●值班小編：⏎姓名 分機或手機`。
- 內文：沒有內文欄位或空白 → 標題段後插 `●內文：<標題去掉｜LIVE／【LIVE】／LIVE>，讓TVBS新聞帶您一起來了解。`（有兩個標題用第一個）。
- 新增的行沿用該單的符號（`●` 或 `◎`）。

## 檢查（擋複製）
新聞事件空白、直播時間空白（18氣象站沒寫時自動算 18:00、不插行；手補插在新聞事件下一行）、FB 粉專一個都沒有、值班小編空白、標題空白（內文因此也無法補）。畫面來源待補只顯示黃色提醒。

## 18氣象站封面提醒
新聞事件含「氣象」時顯示。主播＝內文中 `主播 XXX` 後的名字；封面標題＝內文欄位之後、單子最後的非空行（黃色底框）。
```
18氣象直播封面PNG麻煩小幫手，今日主播是XXX，謝謝!
標題:
<封面標題行>
```

## 值班小編（瀏覽器保存，依班別失效）
早班 08:00～16:30、晚班 16:00～00:00。16:00 後新填算晚班到 00:00；早班填的到 16:30；00:00～08:00 填的到 08:00。過期即清空。

## 其他
- FB 粉專清單預設：新聞、少康、娛樂、國際（固定；需要時改程式）。
- 一次一份：貼上會取代框內舊內容並馬上解析，不保留先前的直播單。
- 卡片標題顯示新聞事件、「重N」加〔更正版〕標籤、直播時間；輸出預覽可直接改，複製以預覽內容為準。
- 工具分類「發文與素材」、tier public、不需外掛。
