# 時間排序以距離現在為準
- 狀態：進行中　- 分支：`codex/sort-distance-now`　- 最後更新：2026-11-07
- 使用者需求：「越靠近現在時間」為最近時間，相反為最遠時間；已確認「開始」。

## 已定案的決定
- 已排程的時間排序使用與現在的絕對時間差；最近由小到大，最遠由大到小。
- 缺少或無效時間一律放最後；時間差相同時以時間先後穩定排序。
- 僅重排畫面已有資料，不增加 Facebook 查詢；保留排序偏好。
