# 排程發布 v2（照網新重做）＋留言總管＋圖片套版快速填入
- 狀態：進行中　- 分支：`claude/fb-backend`　- 最後更新：2026-11-06
- 使用者原話：「目前改的很難用，直接依照既有「網新快速排程」工具的新增工具來做。文章網址填入後會自動讀取、標題會依照原有邏輯自動換行、小編文會照原有格式自動帶入及抓取hashtag。」「請直接到 https://github.com/unnn3ing-oss/-schedulenewnet 去讀取不要用圖片瞎猜，不懂就問我」
- 網新原始碼：`unnn3ing-oss/schedulenewnet`（預設分支 `claude/ecstatic-dirac-ld30l7`），`web/` 底下 `rules.js`、`article.js`、`sched.js`、`config.js`、`app.js`、`index.html`、`app.css`、`editor.js`、`stickers.js`

## 已定案的決定
| 項目 | 決定 |
|---|---|
| 彈窗關閉 | 1A：關閉要確認，確認後清空（同網新 resetAll） |
| 文章連結 | 2B：放在第一則留言。新增「留言小編文」輸入框；空白→「看更多新聞內容\n<該粉專 utm 連結>」；有填→「<輸入內容>\n<該粉專 utm 連結>」 |
| 粉專 | 3A：網新 6 粉專（新聞／娛樂／少康／擠看看／國際＋／氣象）簡稱＋各自 utm；對應表存 D1，後台可查看、編輯簡稱與 utm |
| 排程範圍 | 4B：10 分鐘～30 天（臉書限制） |
| 保留／拿掉 | 保留 Rundown（介面先放「尚未連接」）；拿掉 AI 產生、校錯字、守則判讀、後端預覽、送出紀錄 |
| 純文字 | 6B：底圖（用標題當底圖字、網新色票）＋保留「臉書原生背景」「無底色」 |
| 作圖 | 素材沿用現有（產出一致即可）；漸層與標題位置改用網新參數 |
| 留言機制 | **B 優化版**：一個 Durable Object 總管，鬧鐘設在下一個最早時間；排程時間後第 1、3、5、7、10、15、30、60 秒查，之後每 30 秒；同時段多篇用 `?ids=` 合併查詢；每分鐘 cron 只對「有待留言」粉專抓 `scheduled_posts` 對時 |
| 上限 | **3 分鐘**沒偵測到發出、或留言沒成功 → 停止並通知 |
| 通知 | **A 工具內**：已排程分頁紅色標記＋網頁開著時瀏覽器通知＋失敗項目「補留言」按鈕 |
| 刪除 | 偵測到貼文被刪→取消留言，**不通知** |
| 改時間 | 臉書後台改的：對時抓新時間重設鬧鐘；鬧鐘響時貼文未發布→先重讀時間，若改晚就重設不算失敗；後台「立即發布」→對時發現不在排程清單→查已發布→馬上留言。工具內「已排程」加「改時間」按鈕（`POST /fb/reschedule`，改完立刻更新鬧鐘） |
| 圖片套版 | 補回快速填入（網址→自動選框、標題斷行、主圖），用 `/fetch/article`＋`/fetch/image`，不需外掛 |
| wrangler.toml | **不改**；把要加的 cron／Durable Object 設定給使用者自己貼 |
