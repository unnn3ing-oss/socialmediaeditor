# 排程發布：輸入框 4 行自動長高＋預覽空白畫面
- 狀態：進行中　- 分支：claude/practical-hamilton-inqpbo　- 最後更新：2026-11-20
- 使用者原始需求：「標題輸入框只需要四行、內文輸入框只需要四行，多換行才自動往下拉長」「預覽框裡可像附圖一樣有東西，提示字也要有換行」→ 選 A：「點一次是取選框以便貼入，連點兩下才打開選照片」

## 已定案的決定
| 項目 | 決定 |
|---|---|
| 輸入框 | 標題、貼文內容最少 4 行，內容多就長高（JS 算 scrollHeight，不用 field-sizing） |
| 空白預覽 | 淡藍灰漸層底＋目前框的角落緞帶（有公司素材才畫）＋兩行提示字；只在預覽，不進輸出 |
| 互動（沒照片） | 點一下＝聚焦預覽框（藍框），Ctrl+V 貼上；連點兩下＝開選檔；可拖曳照片進來 |
| 互動（有照片） | 不變（點標題編輯、拖照片、點兩下改標題） |
| 提示字 | 「連點兩下選照片」／「也可以拖曳照片進來，或點一下後按 Ctrl+V 貼上」 |
