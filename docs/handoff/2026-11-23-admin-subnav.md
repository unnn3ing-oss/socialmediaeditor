# 管理頁分類浮出功能清單＋右側只顯示單一功能
- 狀態：已完成（已併入 main）　- 分支：claude/compassionate-cerf-z0hfwl　- 最後更新：2026-11-23
- 使用者原始需求：「管理頁內的各分類頁裡面的各項調整，可以在鼠標移到左側分類項目上時向下彈出該分類有的功能，點選後右側畫面只顯示該功能，並且在上方也有顯示該分類的其他功能。」

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 展開方式（改版，使用者要求） | 手風琴：子功能在分類下方展開、把下方分類往下推；目前分類一直展開；游標停 150ms／鍵盤聚焦展開其他分類；游標在左側時展開過的不收，離開左側才收回（方案 A，避免游標底下換人）；Esc 收起 | 使用者：「把下面其他分類下推的那種列表」 |
| 右側 | 只顯示選中的功能卡片（class 隱藏，不重建）；上方功能分頁列同分類其他功能；只有 1 個功能不顯示分頁列 | 需求 |
| 點分類本身 | 進第一個看得到的功能 | |
| 網址 | `#分類/功能`；舊 `#分類`、`#fb` 等照用 | 重新整理留在原功能 |
| 素材設定、首頁 | 不拆 | 使用者選建議 |
| 使用紀錄舊 rec-tabs | 改用通用功能分頁（拿掉 localStorage `tbx.admin.recTab`，改由網址記） | 統一 |
| 手機 ≤820px | 不浮出，分類列下方功能分頁可左右滑 | 沒游標 |
