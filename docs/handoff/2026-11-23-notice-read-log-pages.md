## 已定案的決定
| 項目 | 決定 |
|---|---|
| 通知狀態 | open（未處理）→ handled（發文者已讀或補留言成功）→ 結案（系統管理者／notify 按已讀＝刪除） |
| 發文者 | 只看 open；按已讀＝handled(read)；補留言成功＝handled(retry)（不再刪除） |
| 系統管理者／notify | 看 open（紅）＋ handled（黃）；按已讀＝結案（1A：發文者還沒處理也直接結案） |
| 黃框消失 | 系統管理者按已讀，或 7 天自動清（2A） |
| 帳號框 | 有 open＝紅光暈；只有 handled＝黃外框不閃 |
| 錯誤紀錄 | 加貼文 ID、摘要、類型（套版／字圖／文字、橫式／Reels）、發布時間、粉專完整名稱、狀態欄＋已讀按鈕（與通知同一套）；錯誤說明中文、原文 title |
| 使用紀錄 | 操作紀錄｜錯誤紀錄 分頁切換（隱藏切換，只顯示有權限的）；每頁 20/50/100（localStorage）；上一頁／下一頁（後端 offset，多讀 1 筆判斷有無下一頁） |
| 推 main | 和「錯誤訊息改中文」（bf595ec）一起 |
