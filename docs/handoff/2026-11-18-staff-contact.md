# 授權名單加分機／手機，直播需求單自動帶入
- 狀態：進行中　- 分支：claude/zen-wozniak-y8862m　- 最後更新：2026-11-18
- 使用者原始需求：「目前有個別使用者管理，可以把直播單時的分機也存到對應使用者資料中，並由使用者輸入時保存或編輯，管理頁也可查看編輯更改。」→「開始」（未另選，採建議）

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 姓名 | 員工登入時帶入名單姓名，可臨時改、不存回 | 建議 1(a)：姓名由管理員管 |
| 分機儲存 | 自動存（停止輸入 0.6 秒或離開欄位），顯示「已儲存」 | 建議 2(a) |
| 未用員工編號登入 | 維持 localStorage＋班別清空 | 不影響原本使用者 |
| 格式 | ≤30 字，數字 # - + 空白 括號；5 位數字自動加 #（前端原規則） | 手機也能填 |
| 對話 | 在同一對話繼續 | 使用者直接說「開始」 |
