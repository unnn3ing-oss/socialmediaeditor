# 排程發布：外掛側邊欄縮小＋文章網址置頂＋標題同步
- 狀態：進行中　- 分支：claude/practical-hamilton-inqpbo　- 最後更新：2026-11-20
- 使用者原始需求：「把目前外掛插件的發文對照YT下載來把介面按鈕縮小到一致，排入RD左邊開關右邊輸入框(都不用那麼大)」「文章網址的位置移到最上面，並自動聚焦」「預覽框可編輯標題，且同步到下方的貼文內容」「標題同步網頁跟外掛插件都要有」

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 側邊欄判斷 | A：fbpost 自己判斷被 `chrome-extension://` 嵌入（`location.ancestorOrigins`）→ `html.is-side` | 不改外掛、不升版號 |
| 網址位置 | 甲：只有窄版（單欄）網址移到最上面；電腦版兩欄不變 | 電腦版網址本來就在右欄最上 |
| 標題同步 | 網頁＋外掛都有；改標題（預覽或標題欄）→ 貼文內容第一個整行 `【…】` 換成 `【新標題】`；沒有該行不補；多行合併，兩邊英數補空格 | 使用者確認 |

## 做法（改哪裡）
| 檔案 | 內容 | 狀態 |
|---|---|---|
| `tools/fbpost/index.html` | 早期 script 加 is-side；網址區塊 | ⬜ |
| `tools/fbpost/fbpost.css` | `.is-side` 縮小規則（按鈕 32／膠囊 36／輸入 40／送出 40、RD 同列）；窄版網址置頂 | ⬜ |
| `tools/fbpost/compose.js` | `titleChanged` 同步 `【】`；開視窗聚焦並捲到網址 | ⬜ |
| `test/e2e/fbpost*.e2e.js` | 側邊欄尺寸、RD 同列、網址置頂聚焦、標題同步兩項 | ⬜ |
