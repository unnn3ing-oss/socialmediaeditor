- 使用者原始需求：純色背景預設隨機色；刪「完成」、產生此張改「下載這張」；貼圖與馬賽克改預覽右下角按鈕才彈出；灰字說明與狀態拿掉，需處理時由下往上彈提醒；標題字移到預覽上方；縮圖列最右「＋」新增、拿掉左側再做一張與全部清除。「管理員登入後在所有介面公司素材與通用素材全部都會出現」。

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 純色背景 | 沒選過顏色就從現有色票隨機一個；選過用上次的 | 切換後預覽要馬上變 |
| 完成概念 | 移除 done／已完成／未完成；主按鈕只剩「下載這張」（當場產生）；全部下載當場產生，缺標題或背景先問 | 使用者要求 |
| 縮圖 | 即時小預覽（約 0.3 秒 debounce） | 沒有完成狀態後縮圖要有內容 |
| 貼圖與馬賽克 | 預覽右下角圓鈕 →上方小視窗；點外面／Esc 關 | 使用者要求 |
| 說明與狀態 | 預覽下灰字（兩行）與 batchStatus、手機 mStatus 拿掉；需處理時底部滑出提醒（約 4 秒、可 ×） | 使用者要求 |
| 標題字 | `#batchPreviewTitle` 移到預覽上方 | 使用者要求 |
| 新增／清除 | 縮圖列最後虛線「＋」框；全部清除＝方案 A：縮圖列右側「全部下載」旁、次要樣式、照樣確認；左側只留使用說明 | 使用者選 A |
| 管理員貼圖 | 只有網站管理員登入（`adm:1`）時，貼圖列＝T 寶 7＋通用 7（細線分隔）；一般公司帳號、未登入不變 | 只有貼圖兩邊都有版本；框／字型只有公司版、浮水印本來就兩者都有 |
