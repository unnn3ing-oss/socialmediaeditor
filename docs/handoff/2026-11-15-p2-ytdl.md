# P2 外掛：YT 下載（tools/ytdl）
- 狀態：進行中　- 分支：claude/upbeat-cray-y5m7m6　- 最後更新：2026-11-15
- 使用者原始需求：「把 videodownload 整套複製進小編工具箱（tools/ytdl），用新的下載助手名稱、只允許新外掛連線，不改 videodownload repo；不做網新排程。」決定：「安裝檔A但可選要不要多下載YT功能、自動更新Ｂ，開始」。

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 來源 | 複製 `unnn3ing-oss/videodownload`（main，`extension/`、`host/`、`web/`、`build.py`、`installers/templates/`），**不改該 repo** | 使用者要求 |
| 下載助手代號 | `com.tbx.ytdl`，顯示「小編工具箱下載助手」，`allowed_origins` 只有工具箱外掛 ID（由 `extension/core/manifest.base.json` 的 `key` 算） | 與舊工具並存不互蓋 |
| 安裝資料夾 | 與 videodownload 分開（名稱含 `tbx-ytdl`／`TbxYtdl`） | 同上 |
| 安裝檔 | 方案 A：工具箱安裝檔不變；YT 下載助手有自己的安裝檔（`tools/ytdl/installers/`）。工具箱安裝教學步驟 1 加**可勾選**「我也要用 YT 下載」→ 同時下載 YT 下載助手安裝檔（Mac 顯示一行指令） | 使用者選 A＋可選 |
| 下載助手安裝檔 | **只裝下載助手**（Python／yt-dlp／Deno／ffmpeg＋登錄 Chrome），不再放外掛資料夾 | 外掛由工具箱安裝檔負責 |
| 自動更新 | 方案 B：搬 `selfupdate.py`；來源固定 `unnn3ing-oss/socialmediaeditor` `main` 的 `tools/ytdl/host/`。外掛自己的檔案由工具箱核心 updater 更新，**拿掉** `extupdate.py`、`install_record.py`、`deploy.js`、`folder-store.js` 等「下載助手幫外掛更新」的部分 | 使用者選 B |
| 引擎更新 | 保留「更新下載引擎 yt-dlp」 | YouTube 改版最常需要 |
| Python 測試 | pytest 只在 CI（新增 `.github/workflows/ytdl-host.yml`），不進 `npm test` | 使用者同意 |
| 外掛版號 | `3.00` | 使用者決定 |
| 側邊欄 YT 分頁 | 不做（P3） | 範圍控制 |
| Instagram Reel | 照 videodownload 保留 | 整套複製 |
