# 排程發布工具（tools/fbpost，公司專屬）
- 狀態：**計畫待確認**（使用者已回「開始」，但新增了「照網新排程新增發文」需求，修正版計畫待確認）　- 分支：`claude/fb-backend`　- 最後更新：2026-11-06
- 使用者原話：「我想參照目前網新排程工具的新增發文方式（介面內容，並且增加目前純文字，純文字希望可以像目前臉書前台手動發布一樣，可以讓純文字選擇預設背景色）」

## 已定案
| 項目 | 決定 |
|---|---|
| 工具 | id `fbpost`、名稱「**排程發布**」、`tier: company`、群組「發文與素材」 |
| 多粉專 | 可多選，逐一送出，失敗可單獨重送 |
| 分頁 | 發文／已排程（含「取消排程」，只能刪未發布）／成效 |
| 分支與上線 | 接在 `claude/fb-backend`；使用者測完說「推」時，fb 後端＋工具一起併入 main |
| 測試方式 | 使用者想等介面做完直接用介面測（排程一篇→已排程分頁取消） |

## 參照來源
`unnn3ing-oss/-schedulenewnet`（公開，`git clone --depth 1`）：`web/index.html` 的 `#modal`（新增發文）、`web/editor.js`（作圖框）、`web/app.js`（純文字底圖 swatches、排程時間 popover：日期＋4 碼時間＋「+30 分／+1 小時／明天」）、`web/article.js`（帶入）。做圖可參考本 repo `tools/pattern/app.js`（同源 QPT：漸層、緞帶框、白 Logo、WHZ 標題字）。
