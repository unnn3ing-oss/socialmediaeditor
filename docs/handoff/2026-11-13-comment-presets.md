# 後台設定「第 N 則留言」預設文字，發文時下拉選用
- 狀態：已完成（已併入 main）　- 分支：claude/affectionate-fermat-36bbfp　- 最後更新：2026-11-13
- 使用者原始需求：「在後台增加可以設定第二則留言預設選項開啟，讓新增排程時的第二則留言可下拉選則後台設定文字內容。」→ 確認：「類似，但預設為『無』，可下拉選則需要的」「不用（延遲）…第二則是需要手動增加並不是同時開啟的」

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 預設 | 下拉預設「無」；**不**自動帶出第 2 則列，也**不**在後台標「預設」 | 使用者確認：仍手動「再新增一則留言」 |
| 範圍 | 第 2、3 則共用同一份清單 | 我的決定（簡單） |
| 清單內容 | 名稱＋內容；最多 20 筆、名稱 ≤ 20 字且不重複、內容 ≤ 8000 字 | 與既有留言長度上限一致 |
| 延遲 | 不放進預設文字，沿用「再新增」的預設 5 分鐘 | 使用者確認 |
| 選了之後 | 內容填進文字框，仍可修改；選回「無」時，文字框內容還是「剛填入的原文」才清空，改過就保留 | 避免誤刪使用者改過的字（我的決定） |
| 沒登入公司密碼／讀取失敗 | 靜默略過、下拉隱藏，不擋發文 | 便利功能 |
| 儲存位置 | 後端 D1 `fb_comment_presets`（`ensureTables` 自動建表） | 文字放後端，和公司素材同層級保護；多人共用 |
| 版號／部署 | 不升外掛版號；**後端需重新部署** | 動了 `server/` |
