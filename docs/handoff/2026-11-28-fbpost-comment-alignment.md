# 側邊欄留言對齊與連結
- 狀態：已完成　- 分支：codex/fbpost-comment-alignment　- 最後更新：2026-11-28

## 做法
使用同一個縮排對齊第一、第二則與下方操作列。第二、第三則使用短標頭。有效文章網址同步為第一則泡泡內的連結。

## 測試
在側邊欄測試網址、排列及送出資料。完成後使用者已確認推送。
