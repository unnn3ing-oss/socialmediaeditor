# 後台警語管理與第一則留言連結
- 狀態：進行中　- 分支：codex/fbpost-comment-alignment　- 最後更新：2026-11-28
- 使用者原始需求：「警語在目前後台也要有可以增加刪除的頁面」「前一個顯示出來的連結是不可被更改的，只有留言本身的小編文可以」

## 已定案的決定
| 項目 | 決定 | 理由 |
| --- | --- | --- |
| 文章連結 | 預覽使用獨立連結，同步文章網址欄 | 只讓小編文可直接編輯 |
| 警語權限 | 沿用活動留言管理權限 | 同為發文留言範本 |
| 預設資料 | 沿用既有內建清單，儲存空清單代表刪光 | 支援舊環境與完整刪除 |
