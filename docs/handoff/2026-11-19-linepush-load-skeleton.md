# LINE 推播載入加速＋骨架
- 狀態：待使用者確認　- 分支：claude/sleepy-sagan-p51rwc　- 最後更新：2026-11-19
- 使用者原始需求：「LINE 推播工具載入速度現在會要長達2~5秒才完成，且載入時預先有的骨架沒有小編工具箱design 的Skeleton載入效果」

## 已定案的決定
| 項目 | 決定 | 理由 |
|---|---|---|
| 字型 `font.line` | 背景載入，先用 Noto Sans TC 畫，好了重畫；輸出前仍等字型 | 原本頂層 await 擋住整個畫面 |
| 貼圖 | 背景載入，貼圖列先放骨架格 | 同上 |
| 黃條／娛樂四格 | 方案 3-1：照舊等這 2 張判斷公司版／通用版 | 使用者選 |
| 骨架 | `tool.css` 加與 `ui/tokens.css` 相同的 `.sk` 光帶；`body.is-loading` 由 HTML 起始，第一次畫完套版後拿掉 | 使用者要求 |

## 做法（改哪裡）
| 檔案 | 內容 | 狀態 |
|---|---|---|
| `tools/linepush/tool.js` | 字型／貼圖背景載入、貼圖列逐張補、載完拿掉 is-loading | ✅ |
| `tools/linepush/tool.css`、`index.html` | `.sk` 動畫、載入中骨架（畫布、頁籤、快速填入、貼圖列） | ✅ |
| `test/e2e/` | 延遲字型／貼圖，畫面先可操作、骨架出現後消失 | ✅ |

純網站，不部署後端、不升外掛版號。沙盒無公司素材，公司模式實際秒數需使用者線上量。
