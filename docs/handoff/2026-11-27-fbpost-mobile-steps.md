# 排程發布手機兩步驟＋頂端膠囊＋圖片按鈕同高
- 狀態：進行中　- 分支：claude/trusting-clarke-h20olv　- 最後更新：2026-11-27
- 使用者原始需求：「按鈕大小不一，重新整理粉專不需要，管理員與已連線粉專都顯示在已連線的那個區塊，游標移過去再顯示」「手機介面時，底下工具列改為取消發文/下一步…按下一步跳出選擇發布粉專、RD開關與SLUG…下方上一步、送出貼文」

## 已定案的決定
| 項目 | 決定 |
|---|---|
| 範圍 | 手機網頁（≤820px 且非 `html.is-side`）才兩步驟；外掛側邊欄、電腦維持一頁 |
| ① 編輯 | 底部只留「取消發文」「下一步」 |
| ② 選粉專 | 上方摘要；RD 開關＋SLUG；粉專清單貼底（順序不變，一列一個，清單內捲動）；底部「上一步」「送出貼文（N 個粉專）」 |
| 取消發文 | 有內容（網址、照片、標題、內文、留言）→ 提醒（寬度自適應，左右 16px、最寬 340）→ 清空回列表；沒內容直接回列表 |
| 頂端膠囊 | 排程發布、影片發布都只顯示「● 已連線」，hover／focus／點一下顯示「已連線 N 個粉專」＋身分；失敗＝紅「● 連線失敗」原因在小視窗；新增發文視窗不放 |
| 重新整理粉專 | 拿掉 |
| 圖片按鈕 | 與「新聞｜娛樂」同高同圓角（網頁＋側邊欄） |
