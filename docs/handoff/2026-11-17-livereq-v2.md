| 項目 | 決定 |
|---|---|
| 顯示 | 一次一張，其他張 hidden（不重建，勾選與手改保留） |
| 複製 | 大按鈕在卡片右上角；成功後自動跳下一張；最後一張顯示「全部完成」；有缺漏時灰色不跳 |
| 導覽 | ‹上一張／第 N／總數 場／小圓點（已複製打勾、可點）／下一張› |
| 粉專勾選 | 輸入區與卡片之間，顯示目前這張的勾選（各張各自保存） |
| 時間 | 標題右邊，`HH:MM`（0925→09:25、21:00開始→21:00、1430→14:30） |
| 貼上框 | 3 行 |
