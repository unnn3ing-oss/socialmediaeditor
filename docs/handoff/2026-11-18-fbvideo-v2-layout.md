# 影片發布 v2：左右兩欄版面、每支影片各自粉專與時間
- 狀態：進行中　- 分支：claude/modest-mayer-dmxfhx　- 最後更新：2026-11-18
- 前一份：`docs/handoff/2026-11-18-fbvideo.md`（v1，尚未併入 main，同分支）
- 使用者原始需求：「左邊1/3為每個影片的預覽圖及標題…右側為點選對應影片的內容，由上而下為，類型、影片標題、影片內文、標籤、授權、下拉式選單可勾選發布的粉專（條列式，與排程發布相同先選擇立即或排程，選排程時才跳出時間）」；「標籤要有可以手動增加的位置」。

## 已定案的決定
| 項目 | 決定 |
|---|---|
| 版面 | 方案 A：左 1/3 列表（縮圖左、標題右、勾選、類型、進度、移除）；右 2/3 選中影片內容；隱藏切換 |
| 右欄順序 | 上傳狀態 → 類型 → 影片標題 → 影片內文 → 標籤（按鈕＋自訂輸入「＋ 加入」）→ 授權 → 發布粉專（下拉、條列、勾選＋立即／排程 select，排程才出時間）＋「套用到全部影片」→ 留言 → RD SLUG |
| 預覽 | 不放播放器；縮圖從影片抓一格 |
| 手機 | ≤820px：上方橫向滑動縮圖列，下方內容 |
| 粉專／時間 | 每支影片各自；底列「全部統一／每支各自」移除 |
| 套用到全部影片 | 複製粉專與時間到其他未送出影片；上傳中且會被取消勾的影片跳過並提示 |
| 送出後上傳失敗 | 顯示「重新上傳」：停掉舊 uploadId、用新 uploadId 開工作階段後自動用已送出內容 publish |
| RD 時間 | 每個粉專各自：排程＝排程時間；立即＝按送出當下 |
| 後端 | `/fb/video/publish` 改收 `pages:[{page, at}]`，每個粉專各自檢查排程範圍 |
