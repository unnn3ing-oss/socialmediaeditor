# 值班早晚班＋通知概述＋即時狀態小視窗＋系統管理者發通知
- 狀態：進行中　- 分支：claude/serene-edison-ws6ma1　- 最後更新：2026-11-23
- 使用者原始需求：「沒有大夜只有早與晚，晚上最晚都是0000下班」；「通知要可以用下拉選單選擇發送『單人/多人/全部』，或依照權限組」「只有系統管理者」「留彈窗最下方，1天後消失」；「錯誤說明都只顯示在錯誤紀錄就好，使用者通知只要重要且正確的概述」；「外掛插件的即時狀態只游標移過去就會有小彈窗跳問題，除非點即時狀態才跳過去列表」。

## 已定案的決定
| 項目 | 決定 |
|---|---|
| 值班 | 只有早／晚。選擇當下 <14:30＝早班，有效到當天 16:30；≥14:30＝晚班，有效到隔天 00:00；頁面開著每分鐘檢查過期 |
| 留言錯誤 | 使用者看到的（首頁通知卡、排程發布列表留言狀態、即時狀態小視窗）只顯示簡短概述（權限不足／臉書限流／臉書暫時無法服務／權杖失效／找不到貼文／前一則失敗未留…）；完整說明（含步驟）＋臉書原文只在管理頁錯誤紀錄 |
| 即時狀態 | 游標移上（或鍵盤聚焦）跳小視窗列出問題；點了才到「已發佈」列表 |
| 手動通知 | 只有系統管理者；收件人下拉：單人／多人／全部／權限組；≤200 字；收件人帳號框黃色閃爍（紅色留言失敗優先）；按「知道了」＝已讀，留在彈窗最下方灰色，已讀 1 天後消失；發送者可看已讀狀態、撤回；寫操作紀錄；隱私權政策補一列 |
