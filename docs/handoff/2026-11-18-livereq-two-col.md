# 直播需求單電腦版左右兩欄
- 狀態：進行中　- 分支：claude/vigilant-fermi-oqzctf　- 最後更新：2026-11-18
- 使用者原始需求：「網頁版用完感覺可以變成左右兩邊的，左邊爲貼上需求單，右邊為成品」

## 已定案的決定
| 項目 | 決定 |
|---|---|
| 斷點 | ≥1024px 兩欄；<1024px 維持 C 版上下排（貼上後縮合） |
| 左欄 ~420px（sticky） | ①：共 N 場＋清空｜值班姓名＋分機並排｜保留小字｜貼上框填滿剩餘高度，電腦版不縮合，顯示全文 |
| 右欄 | ②「成品」（原「逐張確認」）＋③ 底列；完整需求單填滿剩下高度 |
| 整體 | max-width 約 1440px，左右塞進一屏 |
| 不變 | 狀態鈕、跳轉、複製後下一張、18氣象站、值班必填、分機補 #、parse.js |

| 檔案 | 內容 | 狀態 |
